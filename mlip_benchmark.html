Headline. On non-magnetic metals (Pt, Cu, Pd) both MLIPs reproduce the DFT metal–adsorbate bond to within ~0.1Å and pick the right site. On magnetic 3d metals (Ni, Co, Fe) they diverge: SevenNet keeps CO chemisorbed (Co–C 1.77Å, Ni–C 2.01Å, Fe–C 2.25Å) while MatterSim ejects it (Fe–C 4.96Å, Eads≥0). Neither model carries spin, yet they behave very differently — so the “magnetic metals eject strong binders” effect you saw is model-dependent, not inevitable.

How to read this / caveats.
  • The comparison is geometric. Reference numbers are literature-typical PBE/experimental values (see each card’s source) — replace them with your own DFT or an OC20 / Catalysis-Hub pull for a quantitative benchmark.
  • Both MLIPs are spin-free foundation models; MatterSim here is the small 1M checkpoint. A larger MatterSim or a spin-aware model may behave differently.
  • Cell p(3×3), 4 layers, bottom 2 fixed, one coverage; Eads uses each model’s own gas-molecule reference (molecular references for foundation MLIPs are imperfect).
  • A large distance is not always wrong: N₂ is a genuinely weak binder, so a long Ni–N is physical.
How to begin (reproduce / extend). In the isolated venv (~/mlip-bench-venv, has torch + sevenn + mattersim): 
python mlip_benchmark.py --list                     # the curated system list + references
python mlip_benchmark.py --calc emt --systems emt    # validate the pipeline, no GPU/torch model needed
python mlip_benchmark.py --calc sevennet --calc mattersim --systems all --png
python mlip_bench_plots.py                            # figures + montage
Add a system by appending one S(...) row in mlip_benchmark.py (metal, facet, adsorbate, initial site/height, and the reference geometry). To probe the CO/Pt(111) site puzzle, compare the final energy of CO_Pt111_atop vs CO_Pt111_fcc.
