## Homepage and collection fixes

The homepage now uses validated selected DFT references with matching slab and molecular atom counts, labeled as relaxed/SPE references with review indicators and a link to the full table. A DFT reference can appear even when ML energy is absent. ML energies, molecular identities, images and contact measurements are unchanged. Gallery-reference labels do not assert that the gallery image has identical coordinates to the DFT calculation. The homepage selects a relaxed reference preferentially, then preserves its previous functional if available, otherwise using the fixed order r²SCAN, PBE+D3, PBE, BEEF-vdW; it never ranks candidates by energy.

The component collector now recognizes manifest-listed SPE recovery directories as complexes, with canonical molecular identity. This closes a gap where their completed totals were available to the SPE extractor but omitted from the reusable component store.
